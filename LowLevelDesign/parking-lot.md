Designing a Parking Lot System

The parking lot has multiple levels. Each level contains a fixed number of parking spots.

The system supports different types of vehicles, such as bikes, cars, and trucks.

Each parking spot is designed for a specific vehicle size. A spot can only accommodate the appropriate vehicle type.

When a vehicle enters the parking lot, the system assigns an available spot based on its size. When the vehicle exits, the assigned spot is released.

The system continuously tracks the availability of parking spots. It provides real-time updates on occupied and vacant spaces.

The parking lot supports multiple entry and exit points. It also handles concurrent access efficiently to ensure smooth operation.
